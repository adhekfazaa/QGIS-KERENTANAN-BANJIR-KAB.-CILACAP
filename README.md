# QGIS-KERENTANAN-BANJIR-KAB.-CILACAP
Pemetaan Kerentanan Banjir Kabupaten Cilacap menggunakan Sistem Informasi Geografis (SIG) dan analisis weighted overlay. Proyek ini mengintegrasikan beberapa parameter spasial, seperti curah hujan, elevasi, dan kemiringan lereng, yang direklasifikasi dan diberi skor untuk menghasilkan peta tingkat kerentanan banjir.
